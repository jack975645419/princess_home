## 1. 项目定位

给「小公主」做的一个**可爱主题的静态小网页**，整体风格参考**摩尔庄园**：主页是一张卡通俯视地图，
地图上摆着若干建筑，点进建筑就是一个小场景/小玩法。目前第一个场景是**餐厅**。

非商业、非工程化项目，追求的是**可爱、轻量、好改**，所以：

- 纯静态（HTML + CSS + 少量原生 JS），**不用框架、不用构建工具、不用图床**
- 图标一律用 emoji，不引外部图片资源
- 部署在 GitHub Pages，推到 `main` 即发布

## 2. 已实现功能

### FR-01 密码门（进入乐园）

| 项 | 说明 |
| --- | --- |
| 入口 | `index.html` 首屏遮罩 |
| 通关密语 | `dengdeng`（小写匹配，输入时自动 `trim` + `toLowerCase`，所以 `DengDeng` 也能过） |
| 通过之后 | `sessionStorage` 写入 `princess_gate_ok = 1`，遮罩隐藏、地图显示 |
| 刷新页面 | 仍然在乐园里（sessionStorage 在标签页生命周期内保留） |
| 重新上锁 | 顶栏「🔒 重新上锁」按钮，清掉 sessionStorage 并回到密码门 |
| 直接访问内页 | `restaurant.html` 顶部校验，未通过则 `location.replace('index.html')` 打回主页 |

> ⚠️ 已知限制（刻意接受的取舍）：这是**前端趣味遮挡**，密语明文写在 `index.html` 里，
> 不是真正的加密，防不住看源码的人。若将来需要真正保密，要换服务端校验或静态加密方案。

### FR-03 小苦瓜餐厅

- 顶部「← 回到乐园地图」返回按钮 + 餐厅头图卡片（🍽️ + 名称 + 欢迎语）
- 菜单区：卡片网格，点菜品展开/收起对应菜谱，展开时卡片高亮、页面平滑滚动到菜谱
- 「收起菜谱」按钮关闭菜谱面板
- 目前共 **7 道菜**（截至 2026-10-02）：

| 图标 | 菜品 | 一句话卖点 | 关键参数 |
| --- | --- | --- | --- |
| 🦐 | 油焖大虾 | 红亮油润，鲜甜入味，汤汁能拌饭 | 鲁菜油焖，约 30 分钟 |
| 🐟 | 清蒸罗非鱼 | 十分钟搞定，原汁原味 | 水开上汽后蒸 8～10 分钟 |
| 🐠 | 清蒸鲈鱼 | 鲜嫩不柴 | 「8 分钟定律」：一斤左右掐表 8 分钟 + 关火焖 1 分钟 |
| 🍄 | 烤口蘑（蒸烤一体机版） | 一盅鲜汤先喝掉 | 200℃ 烤 12～15 分钟（前 5 分钟可开蒸汽）；附空气炸锅 / 平底锅替代方案 |
| 🍜 | 葱油面 | 小火慢熬的葱油 | 葱白葱绿分开熬，生抽 4 + 老抽 1 + 糖 2 |
| 🍲 | 阳春面 | 清汤猪油青葱 | 三字诀：汤要清、面要爽、葱要青 |
| 🍗 | 卤鸡腿 | 三分卤七分泡 | 卤 20～25 分钟 + 浸泡 30 分钟以上 |

### FR-04 菜谱内容：油焖大虾（其余菜品结构相同：食材 / 做法 / 小贴士 / 来源标注）

- 标注：鲁菜经典做法 · 鲜香甜咸 · 约 30 分钟
- **食材**：大虾 500g、姜 3 片、蒜 4 瓣、葱 2 根、料酒 2 汤匙、生抽 1 汤匙、老抽半汤匙、
  白糖 1 茶匙、盐适量、香醋半汤匙 + 淀粉 1 茶匙（调碗汁，可选）、食用油适量（比平时多）
- **做法 7 步**：处理虾（剪须枪、开背去虾线）→ 料酒姜片腌 10 分钟 → 备料并调碗汁 →
  五成热油两面煎至金黄、锅铲压虾头逼出红油 → 下姜蒜葱爆香 → 倒料汁加水刚没过虾底、
  盖盖中小火焖 5～8 分钟 → 大火收汁撒葱花出锅
- **小贴士 4 条**：油焖要少汤短时；收汁须不停翻动防糊；料酒可换米酒/啤酒，喜辣加辣椒花椒；
  汤汁拌饭拌面别浪费
- 来源标注：整理自网络家常菜谱（鲁菜油焖技法）

## 4. 交互与视觉约定

- 配色：粉（`#ff9ec4` / `#f06292`）+ 草绿（`#8fd694` / `#4caf50`）+ 奶油底 `#fffaf3`，
  文字棕 `#5b4636`
- 形状：大圆角（20～32px）、粗白描边、柔和投影，整体「圆润柔和」风
- 字体：`PingFang SC / Microsoft YaHei / Segoe UI` 系统字体栈，不引外部字体
- 动画：统一 `@keyframes bob`（上下浮动）与 `drift`（云朵漂移），只用 transform，轻量
- 移动端：640px 断点下缩小建筑卡片与间距，地图不横向滚动
- 文案：面向「公主殿下」的口吻，多用 emoji 与波浪号～

## 5. 部署与发布

- 分支 `main`，GitHub Pages 从 `/ (root)` 发布（需在仓库 Settings → Pages 里手动开启一次）
- 发布流程：`git add -A` → `commit` → `git push origin main`，约 1～2 分钟生效
- 本地预览：直接双击 `index.html`，或 `python -m http.server 8000`
- 本机环境无 `gh` CLI，GitHub 上的界面操作（如开 Pages）需要人工点

## 6. 扩展指引（后续加东西照这个来）

- **加建筑**：在 `index.html` 的 `.map-scene` 内复制一个 `.building` 卡片（加一个自己的定位 class
  如 `b-xxx`），再到 `css/style.css` 里给它写 `left/top`；可点的用 `<a class="building" href="...">`，
  未开放用 `<div class="building locked b-xxx">`。
- **加菜品**：在 `restaurant.html` 复制一个 `.dish` 卡片并设 `data-dish="xxx"`，再复制一份
  `<section class="recipe" id="recipe-xxx">`；JS 已按 `data-dish` ↔ `recipe-{id}` 自动绑定，不需要改脚本。
- **加新场景页**：参照 `restaurant.html`，记得顶部加 sessionStorage 校验，防止绕过密码门直进。
